# Task 1: Data Cleaning and Preprocessing – Customer Personality Analysis

## Objective
Clean and prepare the Customer Personality Analysis dataset using Python and Pandas by identifying missing values, duplicates, inconsistent text, date formats, and incorrect data types.

## Cleaning steps performed
1. Inspect shape, columns, data types, and summary statistics.
2. Normalize column headers to lowercase snake_case.
3. Convert blank strings to missing values.
4. Fill missing `income` values using the median.
5. Remove exact duplicate rows.
6. Trim text and normalize capitalization in categorical columns.
7. Parse `dt_customer` as a date with day-first interpretation.
8. Convert known numeric columns to numeric data types.
9. Flag invalid values and potential IQR outliers for manual review.
10. Export the cleaned CSV with ISO date formatting.

## Important data-quality decisions
- Median imputation is used for `income` because it is less sensitive to skew and extreme values than the mean.
- Exact duplicate rows are removed. Repeated customer IDs are reported for inspection rather than automatically deleted.
- Potential outliers are flagged but retained. An unusual value is not necessarily an error.
- The notebook prints the actual counts from the supplied file. Use those run-specific counts in your submission; do not assume counts from another person's analysis.
